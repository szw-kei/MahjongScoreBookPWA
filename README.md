# MahjongScoreBook PWA v7

追加機能:
- 対局履歴の保存（年月日のみ表示）
- 過去の対局一覧・詳細・削除
- 参加者別の累計成績
- 3人打ち / 4人打ちを分けた累計
- 対局数、半荘数、順位回数、平均順位、1位率、ウマ、スコア、合計スコア
- 過去の参加者を次回入力候補として利用できる設計の基礎データを保持
- 現在の会社モード / 倍率は設定として保持し、履歴へは保存しない

## v8
- 対局を記録した時点の収支を履歴データとして保存
- 対局詳細で保存済み収支を表示
- 参加者別の累計成績に収支を表示
- v7以前の履歴は収支を推測せず、収支集計から除外

## v9
- 参加者成績画面をスマホ向けに再設計
- 収支を大きく表示し、4人戦績 / 3人戦績をカード式に表示
- 1〜4着回数、着順率、平均順位、1位率、ウマ、スコア、対局数、半荘数、合計スコア、収支を表示
- 3人戦績は折りたたみ可能

## v10
- 過去に入力した参加者名を名前入力候補として表示
- 入力途中も候補を絞り込み
- 過去の参加者組み合わせをワンタップで再入力
- PWAキャッシュをv10へ更新
